# Орбита: интерактивная демонстрация

Публичная ссылка: https://gyurik05.github.io/orbita-community-demo/

Версия 2026-11-09-v2 учитывает доступную переписку, обе анкеты и расшифровку звонка 6 ноября. Демонстрационные процессы не означают утверждённый регламент или готовность промышленного сервиса.

## Что можно проверить
- Первый экран: отдельная польза для лидера и участника; самостоятельность сообществ и добровольное раскрытие данных.
- Карта: восемь типов связей, фильтры, выбор сообщества, подробности, добавление, изменение и удаление локальной связи.
- Сообщества: участники внутри карточки сообщества, поиск по имени и компетенциям.
- Два маршрута в личном пространстве: 21 вопрос лидеру и 15 шагов визитки участника GR. Шесть калибрующих вопросов добавлены необязательным предложенным блоком.
- Визитка → локальная очередь координатора → одобрение → каталог выбранного сообщества. Показ требует личного согласия; редактирование повторно отправляет карточку на проверку. Отзыв скрывает карточку.
- Запросы → локальная очередь → принятие, уточнение или завершение.
- События: календарь, создание/изменение/отмена, участие, .ics и текст приглашения для ручного использования.
- Обсуждения: темы, комментарии и отзываемый голос текущей демосессии.
- Сценарии: поиск, статусы, вся/персональная лента, присоединение и выход сообщества без удаления сценария.
- Поиск компетенций по словам в разрешённых карточках. Это алгоритм, не подключённый ИИ.
- Открытый экспорт исключает e-mail и закрытые запросы. Отдельная личная резервная копия по явному выбору включает локальные записи и фото; автоматическое восстановление из неё не реализовано.

## Границы и безопасность
Это **локальное демо**, не сервис сбора реальных заявок. Данные сохраняются только в браузере и не объединяются между посетителями. Все примеры вымышлены. Не вводите настоящие персональные данные.

Переключатель ролей служит для тестирования интерфейса. Настоящих учётных записей, серверного разграничения доступа и общей базы нет. Локальная запись доступна владельцу браузера вне зависимости от выбранной роли.

Ничего не отправляется координатору, в Telegram, Google Sheets, CRM или Kodik. Календарный файл и приглашение скачиваются посетителю, рассылка не выполняется. Kodik/«Цех», LLM-вызовы, проверка компетенций и обогащение из открытых источников не подключены. Согласие одного лидера не заменяет согласий участников.

Фото ограничено 2 МБ из-за localStorage. Калибрующие ответы о готовности делиться данными не являются разрешением на их обработку. Рейтинги, валюта и внутренний roadmap не выданы за функции первого релиза.

Для реального запуска необходимы отдельно согласованные сервер, хранение и срок удаления данных, авторизация и права, уведомления/приглашения, API Kodik и независимые проверки. GitHub Pages обслуживает статические файлы и сам по себе этого не предоставляет.

## Исходники и проверка
В `source/` хранятся компоненты без JSX; React поставляется в исходной базовой сборке. `index.html` является готовым статическим артефактом. Сборка: `python source/build.py` при наличии `source/baseline/repo-index.html` и `source/assets/`. Базовая сборка сохранена в source/baseline для воспроизводимости; она не является текущим приложением.

Изменения и этапы проверки описаны в QA.md. Синтаксическая проверка и тесты обработчиков не заменяют полный браузерный аудит.
