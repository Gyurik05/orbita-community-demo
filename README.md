# Орбита · демонстрация сообщества
Открыть демо: https://gyurik05.github.io/orbita-community-demo/

## Что работает
Каталог сообществ и специалистов, совместные сценарии, добровольное подключение, анкета лидера, визитка GR, локальные черновики и перенос снимка сети. Демонстрационные данные вымышлены.

## Границы
Это статический браузерный прототип, не промышленная платформа. Нет общего сервера заявок, реальной отправки координаторам, Telegram-бота, авторизации участников или работающих ИИ-агентов. Сохранения находятся в браузере посетителя. Не вводите реальные персональные данные. Сетевая JSON-выгрузка не включает отдельные анкеты и идеи.

## Исходники и сборка
Готовые файлы GitHub Pages: index.html и assets/.
Воспроизводимые изменения: source/. Внутри source/ выполните `python build.py`; результат будет в source/dist/. Для обновления Pages скопируйте source/dist/index.html и source/dist/assets/ в корень.
Исходный публичный bundle сохранён в source/baseline/repo-index.html; новые компоненты в forms.js, scenarios.js, extra.js, extension.css и user_surface.py. Личных переписок, скриншотов и документов нет.
Проверки и ограничения описаны в QA.md.
